# Лабораторная №2, вариант 12

Камера и освещение куба (правильный гексаэдр) на оценку 4. Первая лабораторная лежит отдельно и здесь не менялась: из неё перенесены куб, проекция, трансформация и анимация. Куб красится одним цветом из панели. Под ним пол и три стены, чтобы было видно, куда падает свет.

Добавлено:

- камера: позиция, поворот и наклон, угол обзора;
- нормали граней, посчитанные по вершинам;
- направленный свет, фоновый свет и материал Блинн-Фонга;
- точечные и прожекторные источники в storage-буферах, их можно добавлять и удалять;
- затухание `1 / расстояние²`, у прожектора мягкий край между внутренним и внешним углом;
- два набора дескрипторов: сцена и модель.

Сборка из каталога `lab2`. Если стоит Visual Studio:

```bash
cmake --preset msvc-debug
cmake --build build-debug --parallel
```

Если Visual Studio нет, а путь к папке содержит кириллицу, пресет MinGW ломается. Тогда:

```bash
cmake -G Ninja -DCMAKE_BUILD_TYPE=Debug -S . -B build-debug
cmake --build build-debug --parallel
```

Запускайте программу из корня `lab2`, иначе не найдутся `shaders/*.spv`.
