# Лабораторная №1, вариант 12

Правильный гексаэдр (куб) на оценку 4.

Сделано:

- один куб, цвета вершин зависят от локальной позиции;
- переключение перспективной и ортографической проекции;
- позиция, поворот и масштаб;
- движение восьмёркой и вращение, пауза, скорость, радиус, высота и скорость вращения;
- цвет из интерфейса умножается на цвет вершины.

Сборка на Windows (Visual Studio), из каталога `vulkan-starter-app`:

```bash
cmake --preset msvc-debug
cmake --build build-debug --parallel
```

Если Visual Studio нет, а стоит MinGW, пресет `mingw-debug` ломается на пути с кириллицей. Тогда:

```bash
cmake -G Ninja -DCMAKE_BUILD_TYPE=Debug -S . -B build-debug
cmake --build build-debug --parallel
```

Запускайте программу из корня `vulkan-starter-app`, иначе не найдутся `shaders/*.spv`. В конфигурации Visual Studio рабочий каталог отладчика уже указывает на корень проекта.
