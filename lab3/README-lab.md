# Лабораторная №3, вариант 12

Текстурирование куба и комнаты на оценку 4. За основу взята вторая лабораторная.

Что добавлено:

- загрузка PNG из папки `textures/` через `stb_image.h`;
- текстурные координаты у вершин куба и комнаты;
- вершинные и индексные буферы перенесены в память GPU через staging-буфер;
- один динамический uniform-буфер для свойств моделей (куб и комната выбираются через сдвиг при привязке дескриптора);
- три текстуры с отдельным набором дескрипторов на каждую и выбор текстуры из списков в ImGui;
- нетривиальное сэмплирование на кубе (двойная выборка со сдвигом от времени и модуляция цвета), включается через push-константы.

Сборка из каталога `lab3`:

```bash
cmake --preset msvc-debug
cmake --build build-debug --parallel
```

Если собираете через MinGW/Ninja:

```bash
cmake -G Ninja -DCMAKE_BUILD_TYPE=Debug -S . -B build-debug
cmake --build build-debug --parallel
```

Запускать из корня `lab3`, чтобы нашлись `shaders/*.spv` и `textures/*.png`.
